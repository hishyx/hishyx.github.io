Engineering Choices

Technical Decisions & Trade-offs

Why I chose these technologies for my projects.

MongoDB vs SQL

Chosen because the JSON-like document structure in MongoDB aligns naturally with JavaScript/Node.js objects. It allowed me to quickly iterate on dynamic e-commerce schemas (like varied product features) while studying backend data structures.

Session-Based Auth vs JWT

I selected session cookies (using `express-session` and `connect-mongo`) because server-side sessions simplify session invalidation and role tracking directly on the server, which works well for MVC layouts.

MVC Architecture

Dividing the codebase into Models, Views, and Controllers prevents route pollution. Separating query logic from response handling makes the code easier to debug and scale as new routes are added.
